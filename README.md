# Gemini Media Telegram Bot (MongoDB)

Bot de Telegram con botones:
- 🎬 Video (Veo)
- 🖼️ Imagen (Nano Banana)
- 🧩 Editar imágenes (2 fotos -> montaje realista IA)
- ✨ HD (toggle para imagen y edición)
- 🔑 Conectar API Key (cada usuario usa su propia key, guardada en MongoDB encriptada)
